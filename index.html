1. Тултип на :hover

Кнопка — якорь (anchor-name). Тултип позиционируется через anchor().

Это тултип — без JS!

2. Popover + Anchor

Нативный HTML-атрибут popover открывает панель по клику. CSS якорь ставит её под кнопкой.

Popover без JavaScript
Атрибуты popover и popovertarget — встроены в HTML. Позиция — через CSS Anchor.

Если подписи не влезают с нужной стороны — браузер сам переключает позицию. Сузь окно.
